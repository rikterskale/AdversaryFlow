# Code of conduct

## Our standards

Be respectful in issues, pull requests, and discussions. Do not harass,
insult, or threaten anyone. Do not share exploit payloads, credentials, or
private environment data.

This project ships dual-use lab commands. Do not ask maintainers for help
weaponizing them, targeting systems you are not authorized to test, or
bypassing the catalog safety model.

## Enforcement

The repository owner may hide, edit, or reject contributions that violate this
code or [ACCEPTABLE_USE.md](ACCEPTABLE_USE.md), and may block repeat offenders.
Report conduct concerns privately using the same channel as
[SECURITY.md](SECURITY.md).
